One line of code-review approval, carrying quiet existential dread: a tired engineer signs off on a pull request whose tests are green and whose purpose nobody remembers anymore.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out python3 main.py
```

Writes the single line to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`).
